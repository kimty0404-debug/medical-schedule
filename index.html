시스템 설정

Google Apps Script URL 설정:
아래에 배포된 Google Apps Script 웹앱 URL을 입력하세요.

사용 방법

  1. Google 스프레드시트를 새로 만듭니다
  2. 확장 프로그램 → Apps Script를 엽니다
  3. Code.gs 파일에 제공된 코드를 붙여넣습니다
  4. 스프레드시트 ID를 코드에 입력합니다
  5. 배포 → 새 배포 → 웹 앱으로 배포합니다
  6. 배포된 URL을 위 설정에 입력합니다
